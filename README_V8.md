# 课序 V8 · 完整交互原型（交付说明）

> 在 V7 原型基础上继续完善，不删除原有自动排程、长期学习、提醒与课程管理内容；V7 原文件保留在 `ui示例（…）/` 目录中，未做修改。

## 〇、本轮局部修订（V8.1 → V8.4）

结构、页面、数据模型与交互均未重写，只在上版基础上做局部调整（继续沿用参考示例的浅底、日期栏固定、无左侧竖条与高信息密度）：

**V8.1**

1. **空档压缩与分时段标签**：午休/晚间空档不再按真实分钟铺满整屏，改为压缩显示（≤30px）；标签按时间段区分——中午为「午休」、傍晚为「晚餐」、其他为「休息」，不再统一显示「午休」。
2. **课表背景更干净**：去掉虚线网格与空档行整行底色，改为极浅实线分隔；选中日期列只保留 4.5% 强调色底；空档仅保留一条细线与一个小标签。
3. **课程色块更显眼**：底色从 12% 加深到约 22% 课程色，边框与文字对比度提高，课程名加粗到 800；跨节高度仍按真实节次计算。
4. **排版层次与配色**：页面标题 30px、章节标题 16px 带强调色竖条、三级字号与间距节奏；截止提醒加优先级色点；设置分组图标按组上色；底部导航激活态加淡色底。课程颜色仍为单一来源、全页面统一。

**V8.2**

5. **首页统计不再分块**：改为「2 门课 ｜ 3 项任务 ｜ 2.75 小时计划学习」的单行数据带，三个数字分别用蓝 / 橙 / 青绿强调，标签用弱化文字色，避免三张卡片平铺。
6. **折叠模块图标重做**：不再使用「日/截/排/标/完」文字字符，改为统一 1.9px 线宽的定制 SVG 图标（日历勾选、铃铛、收件箱、靶心、对勾圆环），保留每模块一个色彩。
7. **说明文字收敛**：移除首页、待办、规划、设置各处的底部说明与长段导语；统一收进「设置 → 使用说明与关于」弹窗（含数据隐私、演示时间、课程颜色、课表交互、排程与提醒、导入导出说明）。
8. **用文字颜色表达层次**：页面眉标、周次/月份、章节标题、统计数字分别使用强调色/辅助色，说明性小字统一弱化，形成「彩色关键数字 → 深色标题 → 弱化说明」的三级阅读顺序。
9. **配色更鲜艳**：强调色由低饱和蓝改为更清亮的蓝（#2F6FD0），课程色板整体提高饱和度，课程色块底色混入比例再加深；深色模式同步提亮强调色。

**V8.3**

10. **去掉图标的色块底座**：折叠模块的线性图标不再带圆角彩色底／边框，只保留彩色描边图标本身；模块数量也去掉胶囊底色，改为纯文字。
11. **整体色调由灰转蓝**：页面背景、画布、分隔线、正文/辅助文字全部换成带蓝调的色阶（背景 #D8E6FB、画布 #E9F2FF），不再依赖大片白底＋灰字；强调色提到 #1F5CF0。
12. **课程色块提高色彩浓度**：课程色块底色混入比例从约 16% 提高到约 32%，色相更鲜明（蓝/青/紫/橙/绿/玫红/青蓝/黄绿…），但仍保持浅底可读，不压成深色块。
13. **模块标题带色**：今日日程（蓝）、截止提醒（玫红）、待安排（橙）、长期目标（青绿）、已完成（灰蓝）分别使用对应色相的深色文字，让列表本身有颜色层次。

**V8.4**

14. **页面背景统一为课表同款白底**：首页、待办、规划、设置撤掉大面积蓝底，内容区与课表一致使用白色表面；色彩集中到课程色块、标题强调色与彩色文字上，整体更干净、也不再偏灰。
15. **保留鲜亮色相**：课程块仍维持较高的色彩浓度与鲜明色相，只是不再用染色页面背景来制造"鲜艳感"；外框展示台的蓝灰底仅用于桌面预览衬托。

## 五、实现要点（便于转 Android）

- 页面内 `CORE` 区块为**无 DOM 依赖的纯函数**：日期换算、教学周反查、单双周/非连续周匹配、节次布局、半开区间冲突、课程配色对比度、下一节课搜索。可直接对照翻译成 Kotlin（`Date`/`LocalDate`、`[start, end)` 重叠判断）。
- 课程数据模型：`courses[].meetings[] = { weekday, startPeriod, endPeriod, parity?, weeks?, room? }`；节次数据 `periods[] = { from, to }`；课表布局全部由这两组数据推导，不写死。
- 课程颜色：`courses[].color` 单一来源；`CORE.toneFor(color, mode)` 生成底色/边框/文字色，因此换主题、改颜色只需重渲染，不需要多套 CSS。
- 长图模式：`?shot=1&view=home|timetable|tasks|planning|settings&group=course|…&theme=dark&wide=1`，其中 `wide=1` 用于完整 7 天课表长图。

## 六、已知限制

1. 这是 UI/交互原型，不是 Android 工程：提醒、闹钟、后台权限、精确排程算法仍按 `计划书.md` 的 P0 阶段开发；本页「智能规划」为固定示例方案。
2. 数据保存在浏览器 localStorage（键前缀 `kexu-v8-`），并从 V7（`kexu-v7-*`）迁移课程颜色、节次时间与深色偏好；清除浏览器数据会丢失。
3. 课表导入/导出仅支持本应用 JSON 备份；CSV/ICS 与「外部 AI 导入」按计划书第 5、6 章在正式版接入。
4. 演示固定时钟（2026-10-26 07:40）用于保证长图与评审的可重复性；正式版使用设备时间。
