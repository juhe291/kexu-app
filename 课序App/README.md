# 课序 App（Android · V0.1）

Kotlin + Jetpack Compose 的安卓端首个可运行版本，按《计划书》的 P0 路线先做「今天 / 课表 / 待办 / 规划 / 设置」五个页面，并把 V8 HTML 原型的视觉与核心交互落到原生实现。

## 已实现（V0.1）

- **今天**：即将开始课程卡片（32sp 课程名 / 19sp 时间 / 13sp 地点教师 / 倒计时）、单行彩色统计、五个可折叠模块（今日日程、截止提醒、待安排任务、长期学习目标、已完成任务），折叠状态持久化。
- **课表**：粘性日期栏（纵向固定）+ 左侧节次时间轴固定 + 中间网格双向滚动，日期与月份跨月显示，上一周/下一周/本周，点击日期列高亮，课程色块按真实节次高度显示，点击查看课程详情；**点空格可直接添加任务或课程**（预填日期/节次），**已安排任务以白底虚线框显示在课表中并与课程区分**；右上「节次设置」直接进入节次时间轴页。
- **待办**：全部 / 已安排 / 待安排 / 已完成筛选，新建任务（关联课程、优先级、时长、截止日期，**可自己选择星期与开始/结束时间**），勾选完成；**长按任务或长期目标弹出更多操作**（完成/恢复、删除）；**长期学习目标可新建**（名称、总周数、每周投入、下一步）。
- **智能规划**：本地启发式：排除课程与已安排任务，寻找未来数日空闲段并给出两段建议（大字号时间卡片 + 首选标记）；**可通过「换任务」选择任意未完成任务**，可「换个时间」或确认加入日程（写回任务计划）。
- **设置**：课程与学期（开始日期、教学周数、每门课程颜色、节次时间轴）、日程与自动规划（可用时间、默认值、拆分、负载、休息）、提醒与闹钟（偏好的保存）、外观（浅色/深色/跟随系统、强调色）、数据管理（恢复示例数据、清除数据、逻辑自检、关于）；每个小节使用浅色标题条分组，设置页与课表「节次设置」支持直接跳到节次页。
- **课程颜色**：每门课程一种颜色，首页、课表、待办、规划、课程详情统一使用；深浅色模式自动计算柔和底色与可读文字色（对比度 ≥ 4.5）。
- **数据**：Room 保存学期、课程、上课安排、任务、长期目标；DataStore 保存主题、强调色、折叠状态、可用时间与默认值。首次启动自动播种与原型一致的示例课程/任务。

## 技术栈与结构

- Kotlin 1.9.25、Jetpack Compose（BOM 2024.10.01）、Material 3、Room 2.6.1（KSP）、DataStore Preferences、Coroutines/Flow。
- `app/src/main/java/com/kexu/app/`
  - `domain/KexuCore.kt`：**纯 Kotlin 逻辑核心**（日期、教学周、单双周、非连续周次、节次布局与空档压缩、冲突判断、课程配色与对比度、下一节课搜索），可直接单元测试。
  - `domain/Models.kt`：学期、节次、课程、任务、长期目标、偏好、下一节课。
  - `data/`：Room 实体/DAO/数据库、示例数据、DataStore 偏好、仓库。
  - `ui/`：主题、ViewModel、五个页面与共用组件。
- `app/src/test/java/com/kexu/app/KexuCoreTest.kt`：21 项 JVM 单元测试（日期、教学周、单双周、非连续周次、空档压缩、跨节高度、时间轴校验、配色对比度、下一节课等）。

## 构建与安装

环境：JDK 17、Android SDK Platform 35 / Build-Tools 35.0.0。项目中的 `local.properties` 指向本机 SDK（`C:/AndroidSdk`，该目录是指向 IDE 自带 SDK 的链接）；用 Android Studio 打开时改成本机 SDK 路径即可。

```powershell
# 在项目根目录（课序App）执行
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
# 安装到手机（需开启 USB 调试）
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

正式版 APK 见 GitHub Releases：<https://github.com/juhe291/kexu-app/releases>（v1.2.4，R8 混淆，约 50 MB，debug 签名，可直接安装）；调试版可用 `./gradlew :app:assembleDebug` 自行构建。

> 项目目录含中文，已在 `gradle.properties` 中加入 `android.overridePathCheck=true`；Gradle 构建时若遇到中文路径问题，可把项目复制/软链到纯英文路径再构建。

## V0.8.0 修正（多格式智能课表导入引擎闭环）

- **图片课表导入（本地离线 OCR）**：PNG/JPG → ML Kit 中文 OCR（模型随 APK 打包，不联网）→ 表格结构恢复（星期表头一行多天/每格一行/单字表头、表头竖向时自动转置、节次标签 `1-2`/`第1-2节`/时间范围经节次时间轴映射）→ 同列文字聚成课程块（支持跨行合并单元格、同格多课程按周数段拆分）→ `CourseImportRecord`；同时支持地大教务 PDF/截图那种「左侧星期分组 + 每行课程列表」版式（按星期标签中线归属课程、同名课程多周次段拆分）。
- **扫描版/混合型 PDF 导入**：先判断 PDF 类型（文字层 / 扫描 / 混合）；文字型仍走 PDFBox 坐标解析（更快更准），扫描版逐页渲染成位图后本地 OCR，混合型把文字层结果与 OCR 结果按记录指纹合并；文字层解析不出课程时自动回退 OCR。逐页渲染 + 识别后立即回收位图，最多 8 页、长边限制 2400，不一次性把整本 PDF 载入内存。
- **可编辑导入预览**：所有格式统一进入同一个预览：摘要（课程/课次、错误、待确认、警告、冲突数）、按课程分组、逐条勾选，点开可改课程名/教师/地点/星期/节次/周次；修改后实时重新校验（冲突、重复、周次越界、待确认），存在致命错误的行不可导入且默认不勾选；确认后才事务写入 Room。
- **CSV / ICS 迁移到统一解析接口**：CSV 支持 BOM、严格 UTF-8、GB18030（中文 Excel）回退，一行一条记录、非法行不静默丢弃并带行号诊断；ICS 支持折叠行、UTC/TZID、RRULE UNTIL/COUNT、EXDATE、BYDAY 多值，无法转换教学周的事件保留原信息并标记待确认。旧 CSV/ICS 能力保持兼容。
- **统一入口**：`UniversalTimetableImport` 负责格式检测（扩展名 + 文件头）→ 对应解析器/学校适配器/OCR → `ImportValidator` 校验（致命/待确认/警告分层、冲突与重复检测）；30MB 文件上限、解析在 IO 线程、协程可取消。
- JVM 测试 **144 个全部通过**（新增 OCR 结构恢复/语义解析 14（含地大「星期分组 + 课程列表」版式）、导入草稿 13、PDF 类型 5、文本解码 8、CSV 16、ICS 20 等），lint 0 errors / 0 warnings。

已知限制（下一版继续）：真机 OCR 准确率/耗时尚未实测；非地大（中国地质大学武汉）格式仍以模板编排/AI 转换为主，通用学校适配器待增强；外部 AI 导出的 JSON 模板暂未接入导入解析。
