## 导入引擎状态（多格式 Universal Timetable Import Engine）

| 格式 | 状态 | 实现位置 | 验证 |
|---|---|---|---|
| CSV | ✅ 统一接口 | `data/imports/CsvTimetableImporter.kt` + `TextDecoding`（UTF-8/GB18030/BOM） | 16 用例 |
| ICS | ✅ 统一接口 | `data/imports/IcsTimetableImporter.kt`（RRULE/EXDATE/TZID/BYDAY） | 20 用例 |
| PDF（文字型） | ✅ 地大适配 | `pdf/PdfLayoutExtractor` + `pdf/CugWhTableAdapter` | 真实 PDF vs XLSX 24/24 一致 |
| PDF（扫描版/混合） | ✅ 本地 OCR | `pdf/PdfTypeDetector` + `ocr/OcrImagePipeline` + `OcrTableRecovery` + `OcrCourseRecordParser` | 结构恢复 15 用例（含地大「星期分组列表」版式） |
| XLSX | ✅ 地大适配 | `data/imports/CugXlsxImporter.kt`（纯 Kotlin 读 xlsx） | 一致性测试 |
| HTML | ✅ 通用表格 | `data/imports/HtmlTimetableImporter.kt`（jsoup + rowspan/colspan） | 2 用例 |
| 图片 PNG/JPG | ✅ 本地 OCR | ML Kit bundled（`ocr/LocalOcrReader`）+ 表格结构恢复 | 同 OCR 用例 + `PdfTypeDetectorTest` |
| JSON 模板 | ✅ kexu-timetable/v1 | `data/imports/JsonTimetableImporter.kt` | 13 用例 |
| 统一入口 | ✅ | `data/imports/UniversalTimetableImport.kt`（检测→解析→校验，30MB 上限，IO 线程） | 集成验证 |
| 可编辑预览 | ✅ | `ui/imports/ImportDraft.kt` + `ImportPreviewDialog.kt`，设置页接线 | 13 用例 |

**导入原则**：冲突允许导入（只提示，课表标记）；致命错误阻止导入；不静默丢行、不编造时间；写库走 Room 事务；OCR 全离线。

**已知限制**：真机 OCR 准确率/耗时未实测；非地大文字型 PDF 目前只有「地大适配器 → 失败则 OCR 兜底」；无限 RRULE 的 ICS 周次留空（按每周解释，会提示待确认）；导入预览暂不支持解析中取消。
